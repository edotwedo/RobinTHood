# Part 3: Apple App Store Privacy Nutrition Labels

Answers for the mandatory App Store Connect **App Privacy** questionnaire.

### 1. Data Used to Track You
* **Answer:** **No**  
* We do not track users across apps and websites owned by other companies.

### 2. Data Linked to You
* **Answer:** **No**  
* There are no user accounts, logins, or user IDs. No data collected is linked to the user's personal identity.

### 3. Data Not Linked to the User
These data types are processed on-device or transmitted ephemerally to inference providers without being linked to an identity:

| Data Type | Collected | Linked to User | Used for Tracking | Purpose | Details |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **User Content $\rightarrow$ Emails or Text Messages** | Yes | No | No | App Functionality | Prompts and chat messages sent ephemerally to selected AI inference engines to generate replies. Not stored by developer. |
| **User Content $\rightarrow$ Photos or Videos** | Yes | No | No | App Functionality | Only photos explicitly attached by the user for vision analysis. Ephemeral inference only. |
| **User Content $\rightarrow$ Customer Support** | Yes | No | No | App Functionality | Reports submitted by the user via the in-app "Report" flag (includes message snippet and optional note). |
| **Diagnostics $\rightarrow$ Crash Data & Performance** | Yes | No | No | Analytics & Advertising | Collected anonymously by Google Mobile Ads SDK for ad delivery and crash metrics. |
| **Identifiers $\rightarrow$ Device ID** | Yes | No | No | Third-Party Advertising | IDFA (if tracking permitted) or instance ID used strictly by Google Mobile Ads SDK for non-personalized/personalized ad display. |
