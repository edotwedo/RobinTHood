FAQ

Straight answers

Is it really free?

Yes. The core runs on keyless free endpoints and your own local models, so there is no subscription and no meter. Pro is a $4.99 one-time unlock for priority routing and custom endpoints, not a monthly plan.

What is a keyless endpoint?

A hosted model you can call without your own API key. RobinTHood ships with OVH and Kilo endpoints wired in, so it works the moment you open it. You can add your own key or endpoint in Pro.

Does it send my prompts somewhere?

Prompts go to the endpoint that answers them, which is how any hosted model works. Nothing goes to RobinTHood itself: there is no account and no server in the middle.

Which Windows versions?

Windows 10 and 11, 64-bit. The binary is self-contained, so you do not need to install a .NET runtime first.

What if an endpoint is down?

The cascade moves to the next free endpoint, then to a local model if one is running, so you keep working instead of staring at a spinner.
