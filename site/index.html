How it works

Start a project. Keep going later.

01

Open the file

Download RobinTHood.exe and open it. Setup can put a shortcut on the desktop, outside Downloads, so you have one place to open Robin.

02

Write in the document

Name the project and write. Robin saves your edits. Reopen it from the project list and the document is still there.

03

Ask only if you want

Turn on writing assistance in Setup, then choose Ask Robin. Save Robin's draft adopts an answer. Update my document revises the saved document after a complete answer. Earlier copies stay under Project options, Previous versions.

Your work

It stays on this PC.

Projects, documents, conversations and previous versions are stored under %LOCALAPPDATA%\RobinTHood\Workspace. There is no cloud sync. Back up that folder if you want another copy. Export a copy from Project options when you want a separate text file. Open project folder shows where that project's files live.

Writing assistance needs the internet and is off until you enable it. When you ask Robin, your request, the current document and the recent conversation are sent to an AI service. You can write, save and reopen projects with assistance switched off.

Updates

0.3.3 is the current download.

On opening, Robin checks GitHub for a newer release. That check does not send your project text. Nothing installs until you choose the update button and confirm. Robin checks the download's size and SHA-256 before it installs, then asks you to restart.

0.3.3 keeps free writing help available through a short gateway blip: requests identify themselves, a 502 or 503 is tried once, and the first words of a long answer can take 45 seconds.

Questions

Straight answers

What does this version do?

It helps with text: lyrics, drafts, notes and planning. It does not generate audio recordings or images.

Do I need an account or a subscription?

No. Download the EXE and open it. There is no Pro purchase in this version.

Which Windows versions?

Windows 10 and 11, 64-bit. You do not install a separate .NET runtime first.

Where else can I get this exact file?

The projects page and the Google Drive link Phil already shared serve this same 0.3.3 file. The GitHub release is the one the in-app updater uses.
